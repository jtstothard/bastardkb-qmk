1. **Search QMK docs and examples:**
```bash

# Search for custom menu definitions
grep -r "customMenu" keyboards/ --include="*.json" -A 5
```

2. **Understand VIA menu JSON schema:**
- Top-level structure: via.json with customMenu array
- Menu item types: slider, uint8, uint16, int8, int16, action, toggle
- Value IDs: must match dilemma_value_id_t enum (0-26)
- Organization: nested menus with labels and containers
- Size limits: VIA has character/structure limits

3. **Document VIA menu item types:**
- **slider**: For continuous values (DPI, scroll divisors)
- **uint8/uint16/int8/int16**: For numeric keycodes with min/max
- **toggle**: For boolean enables (gesture toggles)
- **action**: For save/reset operations
- **container**: For menu organization (grouping related items)

4. **Analyze ploody repo patterns:**
```bash
# Check if ploody has VIA menu examples
git log --all --oneline --grep="via" | head -10
```

Append to DISCOVERY.md with menu hierarchy design:

**Proposed Menu Structure:**

```
Dilemma Settings (root)
├── Pointer
│   ├── DPI Preset (slider: 0-6)
│   ├── Custom DPI (uint16: 200-4000)
│   ├── Sniping DPI (slider: 0-3)
│   └── Pointer Sniping (toggle)
├── Scroll
│   ├── Drag Scroll X (slider: 1-15)
│   ├── Drag Scroll Y (layer: 1-15)
│   ├── Two-Finger Scroll X (slider: 1-15)
│   └── Two-Finger Scroll Y (layer: 1-15)
├── Gestures → Basic
│   ├── Tap to Click (toggle)
│   ├── Two-Finger Tap (toggle)
│   ├── Two-Finger Scroll (toggle)
│   └── Press and Hold (toggle)
├── Gestures → Advanced
│   ├── Three-Finger Swipe (toggle)
│   │   ├── Left Keycode (uint16)
│   │   ├── Right Keycode (uint16)
│   │   ├── Up Keycode (uint16)
│   │   └── Down Keycode (uint16)
│   ├── Four-Finger Swipe (toggle)
│   │   ├── Left Keycode (uint16)
│   │   ├── Right Keycode (uint16)
│   │   ├── Up Keycode (uint16)
│   │   └── Down Keycode (uint16)
│   └── Pinch to Zoom (toggle)
│       ├── Zoom In Keycode (uint16)
│       └── Zoom Out Keycode (uint16)
├── Gesture Keycodes
│   ├── Tap Keycode (uint16)
│   ├── Two-Finger Tap Keycode (uint16)
│   ├── Two-Finger Scroll Up (uint16)
│   ├── Two-Finger Scroll Down (uint16)
│   └── Press and Hold Keycode (uint16)
└── Advanced
    ├── Auto-Snipe Enable (toggle)
    ├── Auto-Snipe Layer (uint8: 0-127)
    └── Force Click (referenced via Press & Hold)
    └── Actions (Save, Reset)
```

**Menu Design Principles:**
1. **Logical grouping**: Related settings together (Pointer, Scroll, Gestures)
2. **Progressive disclosure**: Advanced gestures nested separately
3. **Clear labels**: User-friendly names, not technical terms
4. **Smart defaults**: All settings have sensible defaults marked
5. **Action buttons**: Save and Reset at bottom of menu

**Value ID Mapping:**
- IDs 0-1: System (unhandled, save)
- IDs 2-7: Pointer/Scroll (DPI preset, custom DPI, scroll divisors)
- IDs 8-14: Gesture enables (basic + advanced)
- IDs 15-24: Gesture keycodes (swipes, zoom)
- IDs 25-26: Auto-snipe (enable, layer)

Document each menu section with:
- Container type and nesting level
- Label text
- Content type (slider, toggle, uint8/uint16, etc.)
- Value ID from enum
- Min/max values (where applicable)
- Default values
