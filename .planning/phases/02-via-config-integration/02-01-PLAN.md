<task type="auto">
  <name>Task 2: Create VIA config application function</name>
  <files>keyboards/bastardkb/dilemma/dilemma.c</files>
  <action>
  Add a function `apply_via_dilemma_config(void)` that:
  1. Reads current g_via_dilemma_config
  2. Checks dpi_preset field
  3. Calls get_dpi_from_preset() to get DPI value
  4. Calls pointing_device_set_cpi() with the DPI value
  5. Returns void

  This function will be called:
  - On matrix_init_kb() after loading VIA config
  - After any VIA config change (in the save handler)
  - After DPI preset changes

  Follow the same pattern as the existing maybe_update_pointing_device_cpi() function.
  </action>
  <verify>Compile completes, function is callable from multiple locations</verify>
  <done>Function exists that applies VIA DPI preset to pointing device</done>
