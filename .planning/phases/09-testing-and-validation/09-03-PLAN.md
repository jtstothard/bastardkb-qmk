<task type="manual">
  <name>Task 1: Test basic gestures (tap, two-finger tap, press-and-hold)</name>
  <action>
Test basic gesture detection and VIA enable/disable toggles:

**Test Procedure Part A - Tap Gesture:**
1. Open VIA configurator → "Gestures - Basic" → "Tap to Click"
2. Verify toggle is ON (default)
3. Perform single-finger tap on trackpad
4. Verify left mouse click executes
5. Set toggle to OFF and verify tap no longer produces click
6. Set toggle back to ON

**Test Procedure Part B - Two-Finger Tap:**
1. Navigate to "Gestures - Basic" → "Two-Finger Tap"
2. Verify toggle is ON (default)
3. Perform two-finger tap on trackpad
4. Verify right mouse click executes (or mapped keycode)
5. Set toggle to OFF and verify two-finger tap no longer produces click
6. Set toggle back to ON

**Test Procedure Part C - Press and Hold (Force Click):**
1. Navigate to "Gestures - Basic" → "Press and Hold"
2. Verify toggle is ON (default)
3. Perform long press (>600ms) with single finger
4. Verify force click keycode executes (default: right-click)
5. Set toggle to OFF and verify press-and-hold no longer triggers
6. Set toggle back to ON

**Expected Results:**
- Tap gesture produces left mouse click
- Two-finger tap produces right mouse click (or custom keycode)
- Press and hold (>600ms) produces force click (right-click or custom)
- All gestures can be toggled ON/OFF via VIA
- Disabled gestures don't trigger (firmware filters them out)
- Gesture detection accuracy: no false positives, no missed gestures

**Validation:**
- [ ] Single-finger tap produces left click
- [ ] Two-finger tap produces right click (or custom keycode)
- [ ] Press and hold (>600ms) produces force click
- [ ] Tap toggle ON/OFF works correctly
- [ ] Two-finger tap toggle ON/OFF works correctly
- [ ] Press and hold toggle ON/OFF works correctly
- [ ] No false positive gestures (accidental triggers)
- [ ] Gesture detection feels natural and responsive
- [ ] Save button persists toggle states to EEPROM

**Test Cases:**
- Tap: Quick tap (<200ms), normal tap (200-500ms)
- Two-finger tap: Both fingers tap simultaneously
- Press and hold: 300ms (too short), 600ms (threshold), 1000ms (clear trigger)

**Record Results:**
- Document gesture detection accuracy
- Note any false positives or missed gestures
- Verify VIA toggles work immediately (no reboot required)

<task type="manual">
  <name>Task 3: Test pinch-to-zoom gesture</name>
  <action>
Test pinch-to-zoom gesture detection and VIA configuration:

**Test Procedure Part A - Enable Pinch-to-Zoom:**
1. Open VIA configurator → "Gestures - Advanced" → "Pinch to Zoom"
2. Set toggle to ON (default OFF - opt-in feature)
3. Click "Save"

**Test Procedure Part B - Test Zoom Gesture:**
1. Navigate to "Gesture Keycodes" → set keycodes:
   - Zoom In Keycode = KC_EQUAL (plus/zoom in)
   - Zoom Out Keycode = KC_MINUS (minus/zoom out)
2. Click "Save"
3. Place two fingers on trackpad
4. Pinch fingers together (zoom out gesture)
5. Verify zoom out keycode executes
6. Spread fingers apart (zoom in gesture)
7. Verify zoom in keycode executes
8. Test multiple zoom in/outs in succession

**Test Procedure Part C - VIA Toggle:**
1. Set "Pinch to Zoom" toggle to OFF
2. Verify pinch/spread gestures no longer trigger zoom keycodes
3. Set toggle back to ON

**Expected Results:**
- Pinch gesture (fingers together) executes zoom out keycode
- Spread gesture (fingers apart) executes zoom in keycode
- VIA toggle enables/disables pinch-to-zoom
- Gesture uses distance threshold (100px) to trigger zoom
- 300ms timeout prevents stuck zoom state
- Integer-only distance calculation (no sqrt, for performance)

**Validation:**
- [ ] Pinch gesture (fingers together) executes zoom out keycode
- [ ] Spread gesture (fingers apart) executes zoom in keycode
- [ ] Pinch to Zoom toggle ON/OFF works correctly
- [ ] Zoom keycodes can be customized via VIA
- [ ] Gesture detection requires >100px finger movement
- [ ] Gesture doesn't trigger accidentally with normal two-finger movement
- [ ] Multiple zoom gestures work in succession (no stuck state)
- [ ] Save button persists settings to EEPROM

**Test Cases:**
- Small pinch (<50px): should NOT trigger zoom (below threshold)
- Normal pinch (>100px): should trigger zoom out
- Small spread (<50px): should NOT trigger zoom
- Normal spread (>100px): should trigger zoom in
- Rapid pinch-spread-pinch: should trigger zoom out, in, out (no stuck state)

**Record Results:**
- Document zoom gesture detection accuracy
- Note threshold behavior (min distance to trigger)
- Verify multiple zoom gestures work without getting stuck
