<task type="manual">
  <name>Task 1: Test drag-scroll mode with separate X/Y divisors</name>
  <action>
Test drag-scroll mode functionality and X/Y scroll speed control:

**Test Procedure Part A - Drag-Scroll Toggle:**
1. Press DRGSCRL (DRAGSCROLL_MODE) key to enable drag-scroll
2. Press DRG_TOG (DRAGSCROLL_MODE_TOGGLE) to toggle drag-scroll
3. Move pointer horizontally while drag-scroll enabled
4. Move pointer vertically while drag-scroll enabled
5. Verify horizontal/vertical pointer motion becomes scroll events

**Test Procedure Part B - VIA Divisor Configuration:**
1. Open VIA configurator → "Scroll" → "Drag Scroll X Divisor"
2. Set X divisor to various values: 1, 5, 10, 15
3. After each value, click "Save" and test horizontal scroll speed
4. Navigate to "Drag Scroll Y Divisor"
5. Set Y divisor to various values: 1, 5, 10, 15
6. After each value, click "Save" and test vertical scroll speed

**Expected Results:**
- Drag-scroll toggle works (DRGSCRL and DRG_TOG keys)
- Pointer motion becomes scroll events when drag-scroll enabled
- X divisor controls horizontal scroll speed (1 = fastest, 15 = slowest)
- Y divisor controls vertical scroll speed (1 = fastest, 15 = slowest)
- Divisor range: 1-15 (0 = invalid/unused)
- Higher divisor = slower scroll (more pointer movement per scroll unit)
- Separate X/Y divisors allow different scroll speeds

**Validation:**
- [ ] Drag-scroll mode toggle works (DRGSCRL and DRG_TOG)
- [ ] Horizontal pointer motion becomes horizontal scroll
- [ ] Vertical pointer motion becomes vertical scroll
- [ ] X divisor controls horizontal scroll speed (1-15)
- [ ] Y divisor controls vertical scroll speed (1-15)
- [ ] VIA accepts divisor values 1-15, rejects invalid values
- [ ] Higher divisor = slower scroll (observable speed difference)
- [ ] X and Y divisors work independently (different X/Y speeds)
- [ ] Save button persists divisors to EEPROM
- [ ] No firmware crashes when changing divisors

**Test Cases:**
- X divisor: 1 (fastest), 5 (medium), 10 (slow), 15 (slowest)
- Y divisor: 1 (fastest), 5 (medium), 10 (slow), 15 (slowest)
- Asymmetric: X=1, Y=10 (fast horizontal, slow vertical)
- Asymmetric: X=10, Y=1 (slow horizontal, fast vertical)

**Record Results:**
- Document scroll speed at each divisor value
- Note any observable difference between X and Y scroll
- Verify divisor independence (asymmetric settings)

<task type="manual">
  <name>Task 3: Test scroll divisor independence (drag vs two-finger)</name>
  <action>
Test that drag-scroll and two-finger scroll use independent divisors:

**Test Procedure:**
1. Open VIA configurator → "Scroll"
2. Set "Drag Scroll X Divisor" to 1 (fastest)
3. Set "Drag Scroll Y Divisor" to 1 (fastest)
4. Set "Two-Finger Scroll X Divisor" to 15 (slowest)
5. Set "Two-Finger Scroll Y Divisor" to 15 (slowest)
6. Click "Save"
7. Enable drag-scroll mode and test scroll speed (should be fast)
8. Disable drag-scroll, enable two-finger scroll in VIA
9. Test two-finger scroll speed (should be slow)
10. Verify modes don't interfere with each other

**Expected Results:**
- Drag-scroll uses its own X/Y divisors (fast when set to 1)
- Two-finger scroll uses its own X/Y divisors (slow when set to 15)
- Modes are independent (drag-scroll divisor doesn't affect two-finger)
- Changing drag-scroll divisor doesn't affect two-finger scroll
- Changing two-finger scroll divisor doesn't affect drag-scroll
- Both modes can have different scroll speeds simultaneously

**Validation:**
- [ ] Drag-scroll uses drag-scroll X/Y divisors (not two-finger divisors)
- [ ] Two-finger scroll uses two-finger X/Y divisors (not drag-scroll divisors)
- [ ] Setting drag-scroll divisor doesn't change two-finger scroll speed
- [ ] Setting two-finger scroll divisor doesn't change drag-scroll speed
- [ ] Both modes work correctly with different divisor values
- [ ] Mode switching doesn't corrupt divisor values
- [ ] EEPROM persistence works for both sets of divisors

**Additional Test Cases:**
- Swap settings: drag-scroll = 15 (slow), two-finger = 1 (fast)
- Verify drag-scroll is now slow, two-finger is now fast
- Asymmetric: drag-scroll X=1/Y=15, two-finger X=15/Y=1
- Verify each mode respects its own X/Y values

**Record Results:**
- Document scroll speed for each mode with different divisor settings
- Verify independence by switching between modes
- Note any cross-mode interference or bugs
