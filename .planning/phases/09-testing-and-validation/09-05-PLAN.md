<task type="manual">
  <name>Task 1: Test VIA configurator connection and via.json loading</name>
  <action>
Test VIA configurator discovers Dilemma v3 and loads custom menus:

**Test Procedure:**
1. Flash firmware with VIA support to Dilemma v3 hardware
2. Connect Dilemma v3 to computer via USB
3. Open VIA configurator (https://usevia.app)
4. Verify VIA detects Dilemma v3 keyboard
5. Click on "Dilemma (BastardKB)" in VIA sidebar
6. Navigate to "Menu" tab
7. Verify custom menu loads (not default VIA menus)
8. Check for all 8 menu containers:
   - Pointer
   - Scroll
   - Gestures - Basic
   - Gestures - Advanced
   - Swipe Keycodes
   - Gesture Keycodes
   - Advanced Settings
   - Actions

**Expected Results:**
- VIA detects Dilemma v3 keyboard immediately upon connection
- VIA loads via.json custom menu definition
- 8 menu containers appear in correct order
- No JSON parsing errors or loading failures
- Menu UI renders correctly with all labels and controls
- No VIA console errors or warnings

**Validation:**
- [ ] VIA detects Dilemma v3 keyboard
- [ ] Custom menu loads (via.json parsed successfully)
- [ ] 8 menu containers appear in correct order
- [ ] All menu labels render correctly
- [ ] No JSON parsing errors
- [ ] No VIA console errors or warnings
- [ ] Menu UI renders without layout issues

**Troubleshooting:**
- If VIA doesn't detect keyboard: Check VIA_ENABLE in config.h, rebuild firmware
- If menu doesn't load: Check via.json syntax with JSON validator
- If containers missing: Check via.json customMenu array structure

**Record Results:**
- Document VIA detection time (immediate or delayed)
- Note any parsing errors or warnings
- Screenshot menu structure if possible

- Sniping DPI slider has 4 positions (0-3) mapping to presets
- Drag Scroll toggle shows current state
- Save button persists all values to EEPROM
- No firmware crashes when changing values

**Validation:**

- [ ] Custom DPI rejects/clamps invalid values (<200, >4000)
