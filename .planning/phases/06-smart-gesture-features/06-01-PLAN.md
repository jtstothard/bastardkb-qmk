Append to DISCOVERY.md:

**Force Click (Long Press) Detection Strategy:**

Since MaxTouch lacks hardware pressure registers (based on Phase 3 discovery pattern), implement force click using timing-based detection:

**Firmware State Machine Extension:**
- Detect finger down time using `timer_read32()`
- Track duration in Down or Tapped state
- If duration > threshold before lift → force click
- Else → normal tap

**Threshold Definition:**
- Force click: 500-800ms (macOS long press)
- Normal tap: <200ms (existing DIGITIZER_MOUSE_TAP_DETECTION_TIMEOUT)
- Hysteresis: 300ms gap between tap and force click

**Implementation Location:**
- Extend `digitizer_mouse_fallback.c` state machine
- Add `force_click_detected` flag
- Check `press_and_hold_enabled` from VIA config (already exists from Phase 3)

**Keycode Mapping:**
- Force click → Forward to existing `press_and_hold_keycode` (Byte 16-17, from Phase 3)
- Default: KC_NO (disabled, user configures via VIA)

**Advantages:**
- No special hardware required
- Uses existing state machine timing infrastructure
- Backward compatible with existing tap detection
- VIA-configurable threshold (optional enhancement)

**Disadvantages:**
- Not true pressure detection (time-based proxy)
- May interfere with drag operations (need careful state management)
