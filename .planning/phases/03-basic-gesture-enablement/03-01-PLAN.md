# Discovery findings from web research:
# - Azoteq IQS5xx reports gestures via GESTURE_EVENTS_0 and GESTURE_EVENTS_1 registers
# - GitHub library (lemio/iqs5xx-b000_trackpad) shows TouchData structure with gesture flags
# - Gestures detected: singleTap, twoFingerTap, swipeX/Y_plus/minus, scroll, zoom, pressAndHold
# - These are READ from hardware registers, not enabled via configuration
</context>
