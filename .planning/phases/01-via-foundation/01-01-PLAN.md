# Research findings from discovery agent:
The VIA custom command protocol uses USB Raw HID with packet structure [command_id, channel_id, value_id, value_data].
Key functions: via_custom_value_command_kb() (override point), nvm_via_read_custom_config(), nvm_via_update_custom_config().
EEPROM constraint: 32 bytes maximum for custom config via VIA_EEPROM_CUSTOM_CONFIG_SIZE.
</context>
